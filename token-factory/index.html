HOW TOKEN CREATION WORKS

From token idea to onchain deployment.

Token Factory organizes the standard creation flow into a clear wallet-connected experience. Users choose a supported network, configure token settings, review permissions and approve the final deployment transaction in their own wallet.

01 / CONNECT

Connect your wallet

Start with a supported wallet. HOODBTC Token Factory does not ask for your private key or seed phrase.

02 / NETWORK

Choose a blockchain

Select Solana or a supported EVM network for the token you want to create.

03 / CONFIGURE

Set token parameters

Configure token name, symbol, initial supply, decimals, metadata and supported permission options before deployment.

04 / REVIEW

Review permissions

Check whether any mint, freeze, ownership, metadata or other authority is retained, transferred or revoked where the selected network supports those options.

05 / DEPLOY

Approve onchain deployment

The connected wallet authorizes the blockchain transaction. Network costs and any applicable service fee are shown through the live product flow.

06 / VERIFY

Verify the result

Save the token address and use available explorer and transaction links to inspect supply, authorities and onchain state.

UNDERSTAND THE TOKEN SETTINGS

Know what the form is asking before you sign.

CONFIGURATION

Define the token.

NAME + SYMBOLPublic token identity

Choose the readable name and ticker users will associate with the token.

SUPPLY + DECIMALSQuantity and divisibility

Supply defines the initial quantity; decimals define how finely a token can be divided.

METADATAProject information

Add supported logo, description, website and social information where available.

CONTROL

Understand authorities.

MINTFuture supply control

If a mint authority is retained, additional supply may be possible. Revoking it can remove that capability.

OTHER AUTHORITIESReview network-specific controls

Freeze, ownership, metadata and similar options differ by token standard and network.

WALLETApprove only what you understand

Never enter a seed phrase or private key. Review every wallet prompt before signing.

AFTER DEPLOYMENT

Creating the token is only the first onchain step.

A confirmed deployment creates the token asset or contract. Distribution, liquidity, listings, community, legal structure and market activity are separate decisions.

VERIFY

Save the token address

Record the official mint or contract address and verify it through a compatible blockchain explorer.

DISTRIBUTION

Plan allocation separately

Token Factory does not decide how the supply should be distributed, vested or managed after creation.

LIQUIDITY

Trading is a separate step

Creating a token does not create buyers, a price or a liquidity pool. Tradability requires a separate compatible market and liquidity arrangement.

LISTING

No automatic HOODBTC Trade listing

A token created in Token Factory is not automatically listed on HOODBTC Trade. The products are connected by brand, not by automatic listing.

SECURITY

Protect deployer access

Keep the deployment wallet secure and understand which authorities remain active after creation.

LEGAL

Consider local obligations

Fundraising, token distribution, marketing and promises can create legal or regulatory obligations depending on jurisdiction and design.

TOKEN CREATION QUESTIONS

Useful answers before creating a token.

What is a token factory?+

A token factory is a web application that helps users configure and deploy a standard blockchain token without manually writing the complete smart-contract or token-program workflow themselves.

Can I create a Solana token with HOODBTC?+

HOODBTC Token Factory supports Solana token creation. Users connect a supported wallet, configure token parameters and approve the required onchain transaction themselves.

Can I create an ERC-20 token?+

HOODBTC Token Factory supports token creation on several EVM networks, including Ethereum, BNB Chain, Base, Arbitrum One, Polygon, Avalanche C-Chain and Optimism.

Does Token Factory hold my private keys?+

No. The product is designed around wallet-based approval and does not request or store a user's private key or seed phrase.

Does creating a token make it tradable?+

No. Deployment creates the token onchain. Liquidity, a trading pair, exchange or DEX listing and market demand are separate steps.

Does a new token automatically appear on HOODBTC Trade?+

No. Token Factory and HOODBTC Trade are separate products. Creating a token does not automatically create a HOODBTC Trade market or listing.

Do I still pay blockchain network fees?+

Yes. Blockchain deployments require network transaction costs and, on some networks, account or storage costs. Any applicable HOODBTC service fee shown in the live product is separate from unavoidable blockchain fees.
