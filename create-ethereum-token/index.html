CREATE ON ETHEREUM

From ERC-20 settings to a verified contract address.

Ethereum fungible tokens commonly follow the ERC-20 standard. After deployment, the contract address becomes the primary onchain identifier. Record it carefully and verify the contract state before publishing the address publicly.

ETHEREUM TOKEN FAQ

Questions before deploying an ERC-20 token.

Does creating an ERC-20 token automatically create a market?+

No. Deploying the token creates the contract. Liquidity, trading pairs, listings, buyers and price are separate.

Who approves the Ethereum deployment?+

The connected wallet approves the transaction after you review the network and gas details.

Does HOODBTC need my private key?+

No. Never send a seed phrase or private key to another person to create a token.

Why should I save the contract address?+

Because token names and symbols can be duplicated. The network and contract address are the stronger onchain identifiers.
