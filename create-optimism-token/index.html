CREATE ON OPTIMISM

Deploy a standard EVM token on the selected network.

Optimism is EVM-compatible. The deployed token has a unique contract address on Optimism even if the same name or symbol is used on another chain.

01 / NETWORK

Select Optimism

Confirm the network in Token Factory and in your wallet before signing.

02 / IDENTITY

Set name and symbol

Define the public identity while remembering that token symbols can be duplicated.

03 / SUPPLY

Choose supply and decimals

Review initial quantity and divisibility before deployment.

04 / CONTROL

Review permissions

Understand ownership, minting or other controls shown by the live product.

05 / GAS

Check the live fee estimate

Network gas is required. Confirm Optimism and the transaction estimate in your wallet.

06 / VERIFY

Save the contract address

Verify the contract and deployment transaction with a compatible Optimism explorer.

OPTIMISM TOKEN FAQ

Questions before deployment.

Can two tokens on different networks use the same symbol?+

Yes. Symbols are not globally unique, so network plus contract address is a better identifier.

Does creation automatically make the token tradable?+

No. Deployment creates the token; liquidity and market access are separate.

Who approves the transaction?+

The connected user wallet approves deployment after reviewing the network and transaction details.
