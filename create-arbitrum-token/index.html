CREATE ON ARBITRUM

Deploy a standard EVM token on Arbitrum One.

Arbitrum One is EVM-compatible. A token deployed there has its own contract address on Arbitrum, separate from any similarly named asset on another chain.

01 / NETWORK

Select Arbitrum One

Confirm the selected network in Token Factory and your wallet.

02 / IDENTITY

Set name and symbol

Define the public token identity while remembering that names and tickers are not unique.

03 / SUPPLY

Set supply and decimals

Choose quantity and divisibility before deployment.

04 / CONTROL

Review contract permissions

Understand any ownership, minting or related controls shown in the live product.

05 / GAS

Review network fees

Network fees apply. Check the wallet estimate and Arbitrum network before signing.

06 / VERIFY

Verify the contract

Use a compatible Arbitrum explorer to confirm the contract address, deployment transaction and token state.

ARBITRUM TOKEN FAQ

Questions before deployment.

Is an Arbitrum token the same as an Ethereum token with the same name?+

No. Tokens on different networks are separate onchain assets unless a specific protocol relationship exists.

Does creation automatically create liquidity?+

No. Token deployment and liquidity are separate actions.

Who signs the deployment?+

The connected user wallet approves the transaction after reviewing the network and details.
