CREATE ON SOLANA

A clear path from token settings to deployment.

On Solana, the token is represented by a mint address. Supply, decimals, metadata and authority choices can affect how the token behaves after deployment. Keep the official mint address and transaction signature so you can verify the result onchain.

01 / CONNECT

Connect a supported wallet

Open the official Token Factory and confirm that the selected network is Solana.

02 / IDENTITY

Choose name and symbol

Set the public token name and ticker carefully. Names and symbols are not globally unique.

03 / SUPPLY

Set supply and decimals

Choose the initial quantity and divisibility with the intended token design in mind.

04 / CONTROL

Review authorities

Understand any mint, freeze, metadata or other controls shown by the live product.

05 / APPROVE

Review the wallet transaction

Solana transactions require network fees paid by the connected wallet. Check the live transaction details before approval.

06 / VERIFY

Save the mint address

Verify the mint address, supply and remaining authorities through a compatible Solana explorer.

SOLANA TOKEN FAQ

Questions before deployment.

Can I create a Solana token without coding?+

HOODBTC Token Factory provides a guided web interface and wallet approval flow for standard Solana token creation.

Does creating a token automatically create liquidity or a price?+

No. Deployment creates the token. Liquidity, buyers, trading pairs and price discovery are separate steps.

Who approves the deployment transaction?+

The connected user wallet approves the blockchain transaction. Always verify the network and details before signing.

Should I share my seed phrase with HOODBTC?+

No. HOODBTC Token Factory does not require you to send a seed phrase or private key.
