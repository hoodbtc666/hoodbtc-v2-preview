CREATE ON BASE

Use a clear EVM deployment workflow.

Base is EVM-compatible, so a deployed token is identified by a contract address on the Base network. Keep network identity in mind when sharing an address because the same wallet can operate across multiple EVM chains.

01 / NETWORK

Select Base

Confirm the Base network in Token Factory and in your wallet before deployment.

02 / IDENTITY

Set name and symbol

Choose the public token identity while remembering that symbols can be reused.

03 / SUPPLY

Set supply and decimals

Review quantity and divisibility before signing the deployment transaction.

04 / CONTROL

Review permissions

Understand any ownership, mint or related controls shown by the product.

05 / GAS

Check the live gas estimate

Base deployment requires network gas. Verify the selected network and estimated cost in your wallet.

06 / VERIFY

Verify the contract

Confirm the contract address, supply and transaction through a compatible Base explorer.

BASE TOKEN FAQ

Questions before deployment.

Can I use the same wallet on Base and Ethereum?+

Many EVM wallets support both networks, but each deployment happens on a specific chain. Always verify the selected network.

Does creating a Base token automatically create liquidity?+

No. Liquidity, market creation and token deployment are separate steps.

Does HOODBTC need my seed phrase?+

No. Never send a seed phrase or private key to another person.
