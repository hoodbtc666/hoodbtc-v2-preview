TOKEN DECIMALS GUIDE

DIVISIBILITY / DISPLAY / TOKEN UNITS

Token decimals explained.

Decimals tell wallets and applications how a token's smallest units should be represented. They affect divisibility and display precision, but they do not increase a token's market value, supply quality or legitimacy.

HOW DECIMALS WORK

One whole token can be represented by smaller base units.

If a token uses decimals, software can display fractions of a whole token while the blockchain tracks integer base units behind the scenes. The exact conventions and allowed values can vary by network and token standard.

01 / WHOLE UNIT

What users see

Wallets may display a balance as whole tokens and fractions based on the configured decimal precision.

02 / BASE UNIT

What software tracks

Applications often work with the smallest integer denomination and apply decimals for human-readable display.

03 / SUPPLY

Supply and decimals are different

Supply answers how many token units exist; decimals answer how finely a displayed token can be divided.

04 / VALUE

Decimals do not set price

Changing divisibility does not create market demand or determine valuation.

05 / UX

Think about real usage

Too little precision can be inconvenient for small transfers; unnecessary precision can make interfaces harder to reason about.

06 / VERIFY

Check the deployed token

After creation, inspect the official mint or contract address and confirm the configured decimal value.

COMMON CONFUSION

Decimals are a technical display setting, not token economics by themselves.

DECIMALS FAQ

Quick answers.

What are token decimals?+

Decimals define how finely a token can be divided and how software converts base units into a human-readable balance.

Do more decimals mean a higher price?+

No. Decimals affect divisibility and display, not market value.

Can I ignore decimals when creating a token?+

No. The value affects wallet display and application math, so it should be chosen deliberately and verified after deployment.
