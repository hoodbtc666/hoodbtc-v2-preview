CREATE ON POLYGON

Deploy a standard EVM token and verify it onchain.

Polygon is EVM-compatible, so a deployed fungible token is represented by a contract address on that network. Make the network explicit whenever you publish or verify the token address.

01 / NETWORK

Select Polygon

Confirm Polygon is selected in Token Factory and in the connected wallet.

02 / IDENTITY

Set token identity

Choose the public name and symbol carefully.

03 / SUPPLY

Choose supply and decimals

Review initial quantity and divisibility before deployment.

04 / CONTROL

Review token permissions

Understand any ownership, minting or similar controls shown by the live product.

05 / GAS

Check network fees

The connected wallet must have enough of the network's required gas asset to complete deployment.

06 / VERIFY

Verify the contract

Use a compatible Polygon explorer to confirm the contract address, supply and transaction.

POLYGON TOKEN FAQ

Questions before deployment.

Does HOODBTC control a token after I create it on Polygon?+

Control depends on the token settings and any authorities or ownership options that remain active. Review them before signing.

Does creation create liquidity?+

No. Token deployment and liquidity are separate.

Should I share my wallet seed phrase?+

No. HOODBTC Token Factory does not require you to send a seed phrase or private key.
